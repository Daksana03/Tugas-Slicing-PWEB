🌐 Portal SIAKAD Universitas Jember

Website ini merupakan hasil **slicing desain website dashboard/portal SIAKAD** menggunakan HTML, CSS, dan JavaScript. Website dibuat dengan tampilan yang menyerupai portal SIAKAD Universitas Jember, dilengkapi dengan menu layanan, informasi profil pengguna, serta beberapa interaksi menggunakan JavaScript DOM.

🛠️ Teknologi yang Digunakan

Website ini dibuat menggunakan teknologi dasar web tanpa menggunakan framework CSS seperti Bootstrap atau Tailwind.

* **HTML** — Membuat struktur halaman
* **CSS** — Mengatur tampilan, layout, warna, dan responsive design
* **JavaScript** — Menambahkan interaksi dan manipulasi DOM

💻 Cara Menjalankan

Karena website dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework, website dapat dijalankan secara langsung melalui browser.


📱 Responsive Design

Website dibuat agar dapat menyesuaikan ukuran layar yang berbeda.

🖥️ Desktop

Pada ukuran desktop, dashboard menampilkan area utama dan panel profil di sisi kanan.

💻 Tablet

Layout akan menyesuaikan ukuran layar dengan mengurangi jumlah kolom menu.

📱 Mobile

Pada ukuran layar yang lebih kecil, panel profil dan menu akan menyesuaikan posisi serta ukuran agar tetap dapat digunakan dengan nyaman.

Responsive design dibuat menggunakan **CSS Media Query** tanpa framework tambahan.

---

⚙️ JavaScript & DOM

JavaScript digunakan untuk memberikan interaksi pada elemen website.

Beberapa implementasi JavaScript antara lain:

* Menambahkan event listener pada menu layanan
* Membaca nama menu yang dipilih
* Memberikan konfirmasi sebelum logout
* Mengarahkan pengguna ke halaman logout
* Mengambil dan memanipulasi elemen HTML menggunakan DOM

---

🎨 CSS

CSS digunakan untuk mengatur:

* Layout dashboard
* Grid menu
* Sidebar/profile
* Warna dan typography
* Icon dan gambar
* Hover effect
* Responsive layout
* Background dan visual effect
